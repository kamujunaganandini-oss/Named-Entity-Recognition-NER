# Named Entity Recognition (NER)

## Overview
This project implements Named Entity Recognition using:
- Baseline model (Most frequent tag)
- Logistic Regression (feature-based)
- Conditional Random Field (CRF)

## Key Learnings
- Importance of context in NLP
- Sequence modeling improves performance
- Feature engineering for text data
